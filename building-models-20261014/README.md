# 功能建筑：18类90阶段，无损压缩交付

先恢复，再导入。仓库中的压缩文件或分段不能直接当作GLB使用。

1. 完整拉取本目录，保留目录结构；使用已安装的 Python 3.9 或更新版本，无需额外库或联网。
2. 在本目录运行：

   python3 restore_models.py --output ../building-models-restored

   Windows可将python3换为python。输出目录应位于本交付目录之外；建议使用尚不存在的新目录。
3. 成功后从输出目录 assets/buildings/<类型>/stages/L1.glb 至 L5.glb 导入。保留相邻textures目录。

脚本按清单顺序读取每个gzip分段，核对每段及合并流SHA-256，解压后再次核对原GLB大小和SHA-256。90个模型均保持原始字节，不是重建、减面或降低贴图分辨率。重复运行时只接受内容完全一致的既有文件，拒绝覆盖不同文件；路径穿越及符号链接被拒绝。中断可能留下未写完文件；脚本会拒绝覆盖，应选择新的输出目录重试。

TRANSPORT-MANIFEST.json记录传输分段及原模型hash；BUILDING-MODELS.json和README.txt保持原模型快照原字节，其中的GLB路径指向恢复后的输出目录。35张必要PNG会一并复制到输出目录。原始模型说明中的“完整阶段模型”仅指单阶段可视几何，不是完整工程。

含山墙、仓库吊架、厨房水嘴、酒馆琴体、空港吊钩的已列明修订。仍是离线模型候选，不含完整可编辑BLEND、建模源码、游戏接入及验收；不新增许可证。原创来源边界沿用原模型快照说明。
