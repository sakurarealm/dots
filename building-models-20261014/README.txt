Functional building model snapshot, 18 types / 90 stages.

Each stages/Ln.glb is a complete stage model. Keep the neighboring textures directories: external texture URIs are unchanged. Embedded images are retained byte-for-byte. Models were copied unchanged; no geometry, materials, or source assets were rebuilt.

Revisions: 34 stage gable repairs; warehouse L4/L5 hoist r02; kitchen L1-L5 sink r03; tavern L4/L5 instrument r02; terminal L4/L5 hoist-end r02; inn portable texture packaging r02. Farmstead L1 remains the historical baseline. The smithy r04 standalone sample is not a replacement for the historical five-stage family.

These are offline visual candidates, not accepted art or verified game integration. This snapshot does not include all authoring BLENDs, build sources, gameplay contracts or upgrade logic. Building-model hashes identify exact versions. No new license is granted.

Provenance summary: project-original functional-building geometry and project-original material reuse, including the original r10 Oak/Walnut images reused through the BK-named local style experiment (the BK name is not a third-party-asset license claim). Source provenance also records regenerated furnace and blast-furnace submodels in the historical smithy family. Full authoring provenance remains subject to item-level review before a larger source release.
