# Aether 第二批 · 三件兼容构件样例

这三件是首批1m深A字梁架的原创尺寸/风格兼容样例，仍在独立Blender目录。不是完整建筑，也不代表用户今天工作区里已证实缺少这些资产。没有改动或提交Aether仓库。

## 资产与实测尺寸

- `town_building_floor_bay_v01`：3.50×1.00×0.10m承重木地板，8块长板、3条下托梁、少量齐平五金；按1m进深重复
- `town_building_side_infill_v01`：0.60×0.075×1.90m侧墙填充件，竖板、背撑与深色上下收边；配合当前梁架约0.62m柱间净宽
- `town_building_gable_screen_v01`：3.50×0.085×约1.796m山墙填充屏，竖板斜裁、底边及背撑；在当前梁架上安装底高约2.195m，顶部留通风/装配余量

三件放置原点在底面中心。世界单位1=1m，FBX导出`-Z/Y`；均有LOD0/1/2、隐藏的独立编辑零件、简化碰撞代理和锚点。当前原点/尺寸是在Blender内核对，Unity还未实际导入。

## 去重与复用边界

设计背景来自可核验的`handoff/2026-10-04`提交`0956b0777cf007a7a3b1ed799f7ade777f14c80d`，不冒充用户今天工作区。

已只读检查该提交的195个TownGameplay FBX路径和P1建筑构件源。通用门框、1×2.40m墙板、窗框、台阶、坡道、栏杆、屋面均已存在，因此本批不宣称补齐这些项目资产。本批侧墙是当前2.10m柱高、1m重复梁架的尺寸/风格适配样例；地板与山墙是本次独立组合所用的构件。候选库存在不等于角色通行、材质或碰撞已验收。

沿用首批低频手绘渐变图集，12张共享PNG逐字节与首批相同。本批实际使用木材和少量黄铜两材质，不为每件添加一套纹理或装饰灯。无描边、无强菲涅尔；法线/粗糙度均为浅表面辅助，材质只是Principled审查桥接。

## 几何兼容包络：已测

以首批已评审梁架的实际保存网格测量：

- 地板两侧各约0.060m避开柱体，1m重复模块只在边界相接，包围盒不发生正体积重叠
- 横梁下表面距地板面约1.905m。这是几何净高，不是角色可通行验收
- 侧填充与前后柱体各留约0.010m，安装底高0.10m时顶端距横梁约0.005m
- 山墙最低安装处取实际横梁顶高约2.195m，斜梁下表面法向最小间隙约0.033m，距前中柱约0.0075m

这些测量只证明当前独立样例的包络/平面间隙。没有证明网格碰撞、角色胶囊、导航、雨雪密闭或工程装配器兼容。

## 技术与视觉门

技术复检：米制尺寸、单位缩放、有限坐标、LOD闭合组件/正体积、非流形和零面积、UV面积、五金LOD几何面数保护、源文件保存重开；FBX/GLB往返与贴图路由核验。

独立视觉门逐张看12图，六维0—3分，合计至少13/18且无零分才通过。原始结论、逐图哈希和非阻断改进项在`reviews/`。技术绿不代表好看；Blender图审不代表Unity通过。低LOD不称视觉无损。

## 文件与相对贴图路径

- `source/`：可编辑`.blend`，运行时静态网格和隐藏的`SOURCE_PARTS`不得同时显示
- `exports/<资产名>/`：FBX包含LOD、COL和锚点；GLB仅LOD0材质审查模型
- `textures/`：共享512²PNG，BaseColor、NormalGL、Roughness、HDRP MaskMap；源路径为`//../textures/`，节点图使用的贴图另有打包数据
- `previews/<资产名>/`：12张Blender棚拍，包括5正交、透视、细节、灰模、同机位LOD0/1/2、透明图标
- `previews/compatibility_assembly/`：三跨梁架加本批构件的局部兼容棚拍，只是展示组合，不是完成建筑或Unity实景
- `reports/`：技术、包络与出图记录；碰撞和锚点仅为后续接线参考
- `scripts/`：复跑脚本，CPU2线程、24samples、768px。重复运行会重建同名样件，先备份你自己的修改

分包解压时将本批所有包的内容合并到同一个根目录，保持`source`、`textures`、`exports`、`previews`、`scripts`、`reports`、`reviews`同级。可编辑源文件的相对纹理查找为`source/../textures/`，不依赖云电脑路径。

若需复跑包络/组合审图，将首批放在本批同级的`aether-first-batch`目录。三个新增模型自身和GLB不需要先加载首批梁架。
