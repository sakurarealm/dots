# Reference research archive

Historical research snapshot: 2026-10-09.

This archive contains public-source reference summaries and independently written research methodology. It does not contain private application code, third-party asset packs, copyrighted original screenshots, credentials, or authenticated share links.

See `reference-catalog.json` for identity, official sources, permission boundaries, reviewed versions, actual coverage and unresolved evidence. A public demo is not a source license. Reading selected files is not a full codebase audit. Compile, offline numerical tests, engine execution and visual acceptance are separate stages.

PSX Sky Sampler raw redistribution is expressly excluded. Unidentified social links remain unidentified; similar projects are never substituted. Historical product claims require a fresh check before adoption.

## Research method

1. Establish author → official project → exact source version.
2. Separate code, models, textures, dependencies and service terms.
3. Record exactly which source files and artifacts were read, and which were missing.
4. Distinguish observation, inference and proposed adaptation.
5. Preserve deterministic inputs and isolated, reversible experiments.
6. Validate compile, runtime behavior, visual output and target-device performance separately.
7. Keep simulation state separate from display; preserve world identity, deterministic coordinate sampling and invalidation boundaries.
8. For exploration maps, store persistent exploration state independently of temporary chunk residency or decorative fog. Validate lifecycle, save migration and rendering inputs before selecting an integration point.

This method is an abstract design recommendation, not a claim about any private project's implementation.
